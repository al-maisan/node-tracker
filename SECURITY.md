# Security policy

Please report vulnerabilities **privately** through GitHub's
[private vulnerability reporting](https://github.com/al-maisan/node-tracker/security/advisories/new),
not in a public issue.

Include what you found, how to reproduce it, and its impact. You will get a
reply within a few days. Fixes are released as soon as possible and credited
unless you prefer otherwise.

Supported versions: the latest release.
